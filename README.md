# Kelompok3_206_207
Tugas Proyek Akhir PWD

Proyek akhir ini berupa pengembangan aplikasi berbasis web yang berfungsi sebagai platform untuk mencatat, mengelola dan membagikan ulasan atau review film yang telah ditonton oleh pengguna. Aplikasi ini dirancang sebagai media yang berguna untuk memudahkan pengguna dalam menyimpan riwayat tontonan secara terstruktur serta memberikan penilaian terhadap film, sehingga dapat menjadi referensi bagi pengguna lain dalam menentukan pilihan tontonan.

Secara umum, sistem ini memiliki beberapa fitur seperti registrasi pengguna, login, pencatatan film yang telah ditonton serta penulisan dan pengelolaan review film. Aplikasi ini dibangun menggunakan bahasa pemrograman PHP dan menggunakan database untuk menyimpan data pengguna, data film serta data ulasan. 

Secara keseluruhan, aplikasi ini dirancang dengan alur yang sederhana dan mudah digunakan, sehingga pengguna dapat dnegan cepat memahami cara penggunaan sistem. Dengan adanya proyek ini, diharapkan dapat memberikan solusi dalam pengelolaan review film secara digital.
